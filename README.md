&#x20;  # T-SPOT Bulacan



&#x20;  A tourism website that helps visitors discover heritage sites, nature destinations, festivals, and food in Bulacan, Philippines.



&#x20;  \*\*Live demo:\*\* https://dumpDecoder-dotcom.github.io/tspot-bulacan/



&#x20;  ## Features

&#x20;  - Homepage with featured destinations and highlights

&#x20;  - Sites directory with category and city filters (24 municipalities and cities)

&#x20;  - Itinerary planner interface (duration, interests, site selection)

&#x20;  - Events calendar

&#x20;  - Contact page, login, and registration pages

&#x20;  - Administrator interface for managing sites, events, and users



&#x20;  ## Tech Stack

&#x20;  HTML, CSS, JavaScript, PHP, MySQL



&#x20;  ## My Role

&#x20;  Full Stack Developer



&#x20;  ## Known Limitations

&#x20;  - This is a front-end prototype. The PHP and MySQL scripts are not finished, so forms (login, register, contact) do not save data on the live demo.

&#x20;  - The events calendar and itinerary planner use placeholder content.



&#x20;  ## Running Locally

&#x20;  1. Copy `crud/connect.example.php` to `crud/connect.php` and add your database name.

&#x20;  2. Place the project in your XAMPP `htdocs` folder and open it through `localhost`.
